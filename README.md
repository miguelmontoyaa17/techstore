# 🛒 TechStore Medellín

Sitio web desarrollado como proyecto académico para el programa **ADSO - Análisis y Desarrollo de Software** del **SENA CTM Itagüí**.

---

## 📖 Descripción

TechStore Medellín es una tienda virtual dedicada a la venta de productos tecnológicos para estudiantes, desarrolladores y profesionales. El sitio permite conocer la empresa, explorar un catálogo de productos y contactar al equipo mediante un formulario.

---

## 🚀 Tecnologías utilizadas

* HTML5
* CSS3
* JavaScript
* Git
* GitHub
* GitHub Pages
